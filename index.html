单位换算与采样落点（可复核）

  • 声速 c = 343 m/s（20°C 空气近似，全程常数）。
  • 到达时间：t = d / c，1 m 对应 1/343 = 2.915 ms。
  • 采样落点：n = t · fs = d · fs / c；fs = 48000 Hz 时 1 ms = 48 个样本。
  • 非整数 n 不四舍五入抹掉：用 16 抽头 Hann 窗 sinc 核把脉冲能量按分数延迟分配到相邻样本，表中同时给出浮点 n 与最近整数样本。
  • 幅度：直达声 1/d；反射路径 (Π(1−α)) / d，启用空气吸收时再乘 e^(−m·d)。

计算预算与阶次限制

模型显式忽略的波动效应

  • 几何声学近似：仅当波长远小于墙面尺寸时成立；忽略衍射（棱边绕射、障板阴影区）与干涉（相位叠加、驻波/模态、梳状滤波）。
  • 镜面反射：把墙面视为无限光滑平面，忽略散射/扩散与表面粗糙度；实际材料的方向相关反射未建模。
  • 有限阶早期反射：只计算到设定阶次，不含晚期统计混响（指数衰减尾巴）；不叠加任何随机回声，缺阶即明确报预算超限。
  • 频率无关吸收：α 为单一标量，忽略材料的频率相关吸收与空气高频吸收（可选空气衰减项默认关闭）。
  • 点声源/全指向：声源与听点无指向性，忽略人头相关传递函数(HRTF)、立体声定位与多普勒效应。
  • 凸多面体限制：合法性校验依赖凸性（线段在体内等价于端点在体内）；凹形房间需改用束跟踪/BSP，不在本模型范围。
  • 采样落点用 16 抽头 Hann 窗 sinc 分数延迟近似（非理想带限插值），声速取 343 m/s 常数。
