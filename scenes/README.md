# 听声找隔板 · 展项说明

同一房间、同一声源 S，两个展厅在**起始听点 R0** 听到的首个回波时刻相同，但解释不同：

- **A 厅**（空房间）：首回波来自 **南墙一次反射**。
- **B 厅**（同一房间 + 一块可转隔板）：首回波是 **南墙 → 隔板背面两次反射**。

两个解释在 R0 处不可区分；参观者必须移动听点或转动隔板，找到能排除其中一种解释的观测位置。

## 可重建几何

房间外壳 `10 × 8 × 3.6 m`（x/y 为地面两轴，z 为高度），声源 `S = (4.2, 2.0, 1.7)`，起始听点 `R0 = (7.0, 2.3, 1.9)`，声速 343 m/s，采样率 48 kHz。

| 元素 | 参数 | 作用 |
| --- | --- | --- |
| 南墙 | 吸收 α = 0.10 | 唯一保留强反射的墙面，A/B 两厅的首回波都调用它 |
| 其余墙面/地面/天花 | α = 0.92 | 把多余的一次反射压到可听阈值（−20 dB）以下 |
| 隔板 `partition` | 中心 (6.055, 0.9, 1.8)，宽 2.08 m，高 2.4 m，转角 56.5° | 正面/背面 α = 0.08；两面都参与镜像源反射 |

隔板是**零厚度镜像面**：正面与背面各是一个反射面，路径若“穿过”板材会被逐段遮挡检查剔除（不透射）。因此在 B 厅中：

- 南墙的**一次反射点**恰好落在隔板的声影里 → 被剔除；
- 只有 **南墙 → 隔板背面**的两次反射绕开隔板边缘 → 成为首个可闻回波。

两者传播长度被调到相差 < 1 mm（`Δt ≈ 0.001 ms`），在 48 kHz 下落到同一个脉冲样本（718.6 → 最近样本 719），肉眼与听觉都无法在 R0 处区分。

### 关键数值（`npm run build:exhibit` 实时复算）

| 展厅 | 首回波墙面序列 | 传播长度 | 到达 | 脉冲样本 |
| --- | --- | --- | --- | --- |
| A | `南墙 y=0` | 5.1352 m | 14.9713 ms | 718.625（最近 719） |
| B | `南墙 y=0 → partition:背面` | 5.1355 m | 14.9723 ms | 718.670（最近 719） |

## 交互与求值

在 `index.html` 的「听声找隔板：点选回波求值」面板里：

1. **点选听到的回波**（脉冲图画布或回波列表）→ 显示本次求值的墙面序列、分段传播长度、总长度、到达时间、相对直达声幅度，以及对应的脉冲样本落点。
2. **移动听点 / 转动隔板** → 两厅实时重算。把 B 厅隔板转离 56.5°，双反射解释立刻失效；把听点移出隔板与南墙共同决定的窄区，B 厅可听回波数降为 0，而 A 厅南墙回声仍在。
3. **删去隔板重生成** → 见下节。
4. **载入检查点** → 屏风挡住直达声后，两厅仍各留一条合法路径，凭到达时刻辨认展厅。

## 删去隔板后重新生成

`regenerateWithoutPartition()` 对 B 厅删掉隔板后重新求解，逐条比对可听回波：

- 直达声仍在、距离不变；
- 原来那条 `南墙 → 隔板背面` 首回波消失（它是唯一跨隔板的可听回波）；
- 之前被隔板挡进声影的 `南墙` 一次反射**重新出现**。

即“只有真正经过隔板的回波消失”。`npm test` 的第 9 组断言固定了这条性质。

## 屏风后检查点（每条路线一个）

每条路线在 `scenes/echo-hunt.json` 的 `checkpoint` 中带一块**屏风**，放在 S→R 连线上挡住直达声。此时两厅各自的首条合法路径不同，且到达时刻可区分：

| 路线 | 屏风挡后 A 厅首路径 | B 厅首路径 | 时刻差 |
| --- | --- | --- | --- |
| 路线 1 · 侧墙对照位 | `南墙 y=0` @ 15.175 ms | `partition:正面` @ 10.781 ms | 4.39 ms |
| 路线 2 · 隔板角度扫描位 | `南墙 y=0` @ 13.980 ms | `partition:正面` @ 8.856 ms | 5.12 ms |

读者在直达声被挡住时，仍可凭第二条合法路径的到达时刻判断自己身处哪个展厅。**移动屏风**（沿垂直视线方向平移）即可重新验证：屏风偏离到 −0.30 m 时两厅首路径都退回南墙、时刻差归零，说明该判别依赖屏风的位置。`build-exhibit` 第 6 节会把这条扫描打印出来。

## 文件

- `scenes/echo-hunt.json` — 场景规格（由单一真源生成，见下）
- `src/exhibit-spec.js` — 场景规格唯一真源（浏览器与 Node 共用）
- `src/scene.js` — 矩形外壳 + 可旋转零厚度板材
- `src/scene-solver.js` — 带遮挡的镜像源求解器（逐段可见性、板材不透射）
- `src/exhibit.js` — 求值、删板重生成、检查点判定、路线试听
- `src/exhibit-ui.js` — 点选回波 / 移动听点 / 转隔板 / 检查点面板
- `scripts/build-exhibit.mjs` — 从真源重建场景并校验全部约束
- `reference/exhibit-reference.json` — 约束校验参照结果
- `reference/route-assets.json` — 两条路线的逐格脉冲峰表（可试听素材）

## 复现

```bash
npm test                    # 全部断言（含展项 4 组）
npm run build:exhibit       # 校验设计约束，打印全部数值
npm run build:exhibit:write # 重新生成 scenes/echo-hunt.json 与 reference 素材
npm run serve               # 打开 http://localhost:8000 看展项面板
```

## 模型边界

几何声学近似：零厚度板材、镜面反射、频率无关吸收；不计边缘绕射（因此隔板边缘的声影是硬边界，隔板稍一转开回波就消失）、散射与任何晚期混响。可听判据是相对直达声 −20 dB 的幅度阈值，用于把与答案无关的弱反射排除在“首个回波”之外。
